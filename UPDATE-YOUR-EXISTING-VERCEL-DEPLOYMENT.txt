UPDATE YOUR EXISTING VERCEL DEPLOYMENT
======================================

Your deployment is already READY. This project replaces the Google Apps Script
storage layer with direct Google Drive API access. Do NOT try to set the old
GOOGLE_APPS_SCRIPT_URL or GOOGLE_APPS_SCRIPT_SECRET keys; they're gone.

1. EXTRACT THIS ZIP.
2. Copy its files into the EXISTING GitHub repo connected to Vercel.
   Replace the old lib/, scripts/, web/, api/, README.md, package.json,
   vercel.json, server.js and root files as applicable.
   The google-apps-script/ folder is no longer needed; delete it from Git.
   DO NOT commit .env.local or other secrets.
3. From the existing repo, run:

     git add -A
     git commit -m "Replace Apps Script with direct Google Drive API storage"
     git push origin main

4. Follow README.md Steps 1-2 to enable Google Drive API in your Google Cloud
   account, create a Desktop OAuth client, then run npm run connect:drive.
5. In Vercel > YOUR PROJECT > Settings > Environment Variables, set:

     WEDDING_PASSWORD=STWed2027
     WEDDING_SESSION_SECRET=<unique random 64-character hex key>
     GOOGLE_CLIENT_ID=<your OAuth client ID>
     GOOGLE_CLIENT_SECRET=<your OAuth client secret>
     GOOGLE_REFRESH_TOKEN=<value generated by npm run connect:drive>

   Optional: GOOGLE_DRIVE_FOLDER_ID=1ihLbsZeSl8hZ37Bec7mijpX6zkqr2IC4

6. Redeploy and sign in; add a test task, refresh, and inspect your Drive folder.

IMPORTANT: Do not send GOOGLE_CLIENT_SECRET or GOOGLE_REFRESH_TOKEN to other
people. Password alone does not secure the Drive folder if it is shared publicly.

If you choose to use a different branch than main, push that branch instead.
