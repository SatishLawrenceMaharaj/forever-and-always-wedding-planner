UPDATE THE EXISTING VERCEL SITE (Forever & Always Version 3)
=========================================================

YOUR SCREENSHOT'S ERROR:
"Could not load the page." came from the application when its Node.js
handler failed to find login/app HTML files inside the Vercel function.
This release embeds all website pages, CSS and JS in lib/web-assets.js.
A production-style login/assets test passes without any Google Drive setup.

GOOGLE DRIVE STORAGE:
The app no longer needs the Google Cloud Console, OAuth desktop client,
GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, or GOOGLE_REFRESH_TOKEN.

Private Google Drive cannot accept writes from a Vercel application just
because a folder link is supplied. Google requires account authorization.
The free, Google-native Google Apps Script Web App performs that narrow job.
It is a separate Google service but no Google Cloud project or paid
subscription is required to configure it for this personal app.

STEP 1: In your wedding-planner GitHub repository, replace the old project
files with all files from this ZIP. Delete the old lib/drive.js and
scripts/connect-google-drive.mjs if present. Keep .env.local out of Git.

STEP 2: Push to main so Vercel automatically deploys the new code.

STEP 3: Under Vercel Project > Settings > Environment Variables add:
  WEDDING_PASSWORD          = STWed2027
  WEDDING_SESSION_SECRET    = your existing random session secret (>=32 chars)
  GOOGLE_APPS_SCRIPT_URL    = web app URL ending in /exec
  GOOGLE_APPS_SCRIPT_SECRET = your APP_SECRET in Google Apps Script

You can leave GOOGLE_DRIVE_FOLDER_ID in Vercel, but it is optional; the
folder ID is already configured inside google-apps-script/Code.gs.

STEP 4: How to obtain the two Apps Script values (free, no GCP project):
Follow google-apps-script/SETUP.md in this ZIP. Copy Code.gs to
https://script.google.com/home/projects/create and deploy as Web app.

STEP 5: Redeploy after setting environment variables, sign in with
STWed2027, create a test task, and check your Google Drive folder for
To Do.json. Move the task to Done to watch it move to Done.json.

The password screen SHOULD WORK without Drive connected. The app will
show an explicit storage configuration message only after logging in.
On Vercel, it refuses to use disposable local storage.

If Google Apps Script is unacceptable too, there is no functional way for a
private Google Drive folder and a Vercel-hosted Node application to sync
without SOME Google-authorized API/service. Google Drive for Desktop is an
alternative only for apps running locally on a synced computer, not Vercel.
