ONE-TIME GOOGLE ACCOUNT CONNECTION:
1. Create a Google Cloud project and enable Google Drive API.
2. Configure Google Auth Platform consent (add your email as test user).
3. Create an OAuth 2.0 'Desktop app' client.
4. Copy GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET to .env.local.
5. Run: npm run connect:drive
6. Open the printed Google login URL on the same PC and approve access.
7. Copy GOOGLE_REFRESH_TOKEN from .env.local to your Vercel env vars.
8. Push this revised code to GitHub and redeploy in Vercel.

IMPORTANT: External Google OAuth consent apps in Testing mode generally issue
refresh tokens that expire after 7 days. See README.md for production consent,
security implications and screenshots guidance.
