FOREVER & ALWAYS — FREE GOOGLE DRIVE FOLDER EDITION (VERSION 3)
============================================================

THE EXISTING VERCEL ERROR "Could not load the page" WAS FIXED by embedding web pages into a JavaScript module so they ship with the serverless function.

TO UPDATE VERCEL:
1. Replace the contents of your GitHub wedding planner repo with this project.
2. Commit/push to the `main` branch.
3. In Vercel set these environment variables:
   WEDDING_PASSWORD = STWed2027
   WEDDING_SESSION_SECRET = 64 random hex characters
   GOOGLE_APPS_SCRIPT_URL = your deployed Google Apps Script /exec URL
   GOOGLE_APPS_SCRIPT_SECRET = matching Apps Script APP_SECRET
4. Redeploy. If you have not set up Google Apps Script yet, the login screen WILL still work, but planning data cannot be saved until storage is connected.

NO GOOGLE CLOUD CONSOLE, OAUTH CLIENT, OR DATABASE NEEDED.
The free Google Apps Script is the necessary Google-native authorization bridge: Vercel cannot write to a private Google Drive folder without authorization.

SET UP YOUR DRIVE IN 5 MINUTES:
Open `google-apps-script/SETUP.md` and follow the checklist. The script creates `To Do.json`, `In Progress.json`, `Done.json` and the other planning files as readable JSON text, plus a folder for photos.

LOCAL TESTING (NO GOOGLE ACCOUNT REQUIRED):
Double-click START-WEDDING-PLANNER.bat, or run npm run dev.
Open http://localhost:3000 and enter STWed2027.
This creates its own .env.local and .local-data on your PC, excluded from Git and Vercel.
Local demo data IS NOT shared with Drive.

SITE UPDATE NOTE: Deleting or editing existing Google Drive JSON files outside the website can cause data errors; keep a backup and edit through the app.
